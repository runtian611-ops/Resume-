## 2. 分步记录

### 步骤 1：需求分析（docs/01-需求分析.md）

- **改动**：产出功能需求、非功能需求、HR 受众分析、完整功能清单、约束与验收标准。
- **要点**：明确「纯静态、无后端、无数据库、不编造经历、网站与 PDF 一致、UI 克制可读性优先」。

### 步骤 2：技术选型（docs/02-技术选型.md）

- **改动**：技术栈说明、选型理由、替代方案对比。
- **要点**：选 Vue3 + Vite + Tailwind CSS + Mermaid；说明为何采用纯静态方案（零服务依赖、部署简单、加载快、成本低）。

### 步骤 3：UI 调研（docs/04-UI调研总结.md）

- **改动**：调研 21 个真实开源作品集仓库，总结布局/配色/交互/可复用设计，标注参考链接与避坑点。
- **结论**：单页多区块 + 锚点导航；Hero 3 秒讲清「你是谁、会什么、怎么联系」+ 双 CTA；技术栈用标签不用进度条；少色高对比单强调色；明暗主题 CSS 变量 + `data-theme` + localStorage；动效仅滚动入场 + Hover 微反馈；移动端优先。

### 步骤 4：架构设计（docs/03-架构设计.md）

- **改动**：整体架构 Mermaid 图、模块划分、页面结构说明。
- **要点**：单页应用 + 数据驱动（`resume.js` 为唯一数据源），组件化划分 10 个 Section 组件。

### 步骤 5：工程脚手架

- **改动**：`package.json`、`vite.config.js`、`tailwind.config.js`、`postcss.config.js`、`index.html`、`.gitignore`、`public/favicon.svg`。
- **遇到的问题与解决**：
  - 环境未安装 pnpm → 统一使用 npm。
  - GitHub Pages 子路径资源 404 → `vite.config.js` 配置 `base: './'`（相对路径）。
  - 首屏防闪烁 → `index.html` 内联脚本提前根据 `localStorage`/`prefers-color-scheme` 设置主题 class。

### 步骤 6：全局样式与主题

- **改动**：`src/style.css`（主题变量、组件样式类、滚动入场动画）、`src/composables/useTheme.js`（主题切换）、`src/utils/scrollReveal.js`（IntersectionObserver 滚动动画）。
- **要点**：明暗主题用 CSS 变量 `--c-*`，`html.dark` 切换；强调色按钮用 `--c-accent-contrast` 保证两种主题下对比度；`prefers-reduced-motion` 下禁用动画。

### 步骤 7：唯一数据源（src/data/resume.js）

- **改动**：集中管理简历数据（基础信息、教育、实习、技能、荣誉、项目、联系），网站与 PDF 共用内容。
- **要点**：项目 `cover` 字段留 `null`（暂无真实截图），卡片渲染占位视觉，不编造截图。

### 步骤 8：页面组件开发

- **改动**：`NavBar`、`HeroSection`、`AboutSection`、`SkillsSection`、`ExperienceSection`、`ProjectsSection`、`ProjectCard`、`ProjectModal`、`ContactSection`、`FooterSection`。
- **遇到的问题与解决**：
  - 项目详情架构图若同步加载会阻塞首屏 → 在 `ProjectModal` 内动态 `import('mermaid')`，打开详情才加载。
  - 架构图在暗色主题下文字与背景对比不足 → 架构图容器固定白底。
  - 中文 PDF 文件名在 URL 中需编码 → 文件用 ASCII 名 `Resume-NiuRuntian.pdf`，`<a download>` 属性用中文名「牛润田-简历.pdf」。

### 步骤 9：ATS 友好简历 PDF

- **改动**：`scripts/generate_resume.py`（用 python-docx 生成单栏 DOCX）→ LibreOffice Kit 转 PDF → `public/resume/Resume-NiuRuntian.pdf`。
- **要点**：单栏排版、无表格、无图片、无文本框、标准字体、标准标题，保证 ATS 可完整抽取文本；内容与 `resume.js` 完全一致，实习经历无描述则只写公司/岗位/时间，不编造。

### 步骤 10：README 与文档补齐

- **改动**：`README.md`（面向 HR）、`docs/05-部署方案.md`、`docs/06-开发计划&分步记录.md`、`.github/workflows/deploy.yml`（GitHub Pages 自动部署）。

### 步骤 11：本地自测

- **改动**：`npm install` → `npm run dev` 启动验证 → `npm run build` 打包验证 → `npm run preview` 预览。
- **检查项**：页面加载、主题切换、PDF 下载、项目详情弹窗与架构图、响应式布局、外链跳转。

### 步骤 12：推送到 GitHub

- **改动**：`git init` → `git add` → `git commit -m "feat: init 个人简历作品集静态网站"` → `git push` 到 `main`。
- **遇到的问题与解决**：
  - 本机无法直连 github.com:443 → 检测到本地代理端口 7897，执行 `git config http.proxy http://127.0.0.1:7897` 后经代理访问。
  - 远程已存在自动生成的 `Initial commit`（占位 README）→ `git rebase origin/main` 并保留本项目 README 解决冲突。
  - 原 PAT 缺少 `workflow` 权限，推送 `.github/workflows/deploy.yml` 被 GitHub 拒绝 → 更换带 `workflow` 权限的 token 后重试成功。
  - Pages 未启用导致首次自动部署失败 → 通过 REST API 开启 Pages（`build_type: workflow`）并重跑工作流，部署成功。
- **结果**：公网访问 <https://runtian611-ops.github.io/Resume-/>。

### 步骤 13：视觉增强（粒子网络 + 3D 倾斜）

- **改动**：新增 `src/components/HeroParticles.vue`（Canvas 粒子网络，无第三方依赖），`HeroSection.vue` 增加背景层与 3D 倾斜。
- **要点**：粒子低密度、随主题变色、尊重 `prefers-reduced-motion`；3D 倾斜仅在精确指针设备启用且幅度很小（约 1.5°~2°），保证「克制、不喧宾夺主」。
